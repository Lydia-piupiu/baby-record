📷识别

单一数据源：AI 吐 JSON、或从源文件复制 HTML 片段， 都在页面内解析后走同一个写入口 addEvent()。 AI 不直接改写 HTML。照片本身不入库，只留结构化结果。
同一个数据源，两个解析入口，语义不同别混用：
· JSON = 整包替换：预览影响面 → 手输「替换」二字 → 替换前自动导出快照（下载 + localStorage 双份）。当前库里所有数据被覆盖。
· HTML 片段 = 增量追加：只补「归属日」那一天的明细， 逐条走 addEvent(rec,'photo')，其余 207 天不受影响。
两者都汇到同一个写入口 addEvent() —— 不是两条链路，是一条链路的两个解析器。 带 carry / 跨夜归属的行一律丢弃（跨夜区渲染期算，不落库）。 出生日期不采信任何导入值，强制回写封板的 2026-01-05。 照片本身不入库，只留结构化结果。
